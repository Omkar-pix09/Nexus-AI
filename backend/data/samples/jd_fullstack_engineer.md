# Job Description - Full-Stack Engineer (Fresher) (SAMPLE DATA)

Build web products with React and TypeScript on the frontend and Node.js with Express on the backend. You will design REST APIs, work with MongoDB and SQL databases, and deploy to the cloud.

Requirements: JavaScript and TypeScript, React, Node.js, Git, testing with Jest, and an understanding of system design basics. Docker and CI/CD experience is a plus. Interviews include data structures and algorithms rounds.
