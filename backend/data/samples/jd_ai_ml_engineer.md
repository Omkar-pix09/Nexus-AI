# Job Description - AI/ML Engineer (Fresher) (SAMPLE DATA)

We are looking for engineers who can build LLM applications. You will design RAG pipelines using LangChain, embeddings and a vector database such as pgvector or Qdrant, and expose them through FastAPI services.

Requirements: strong Python, machine learning fundamentals, statistics, SQL, and Git. Experience with prompt engineering and deep learning with PyTorch is a plus.

You will own evaluation: define metrics such as precision, recall and groundedness, build benchmark sets, and track regressions. Docker and basic cloud deployment are expected. Solid data structures and algorithms knowledge is tested in interviews.
